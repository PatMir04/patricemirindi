About this dashboard

Data comes straight from the World Bank Indicators API (World Bank Open Data) each time you change a setting, so it shows the latest published figures. Gaps mean the World Bank has no value for that country and year. Survey-based indicators such as poverty and account ownership are only available in survey years.

Built with plain JavaScript and Chart.js. Want something like this for your own programme or organisation's data? Let's talk.
